### 復習：2層MLPのFoward

分類タスクを考える．クラス数は$C$とする．
まず入力を$x$とする.
$$
\begin{align}
z_1 &= W_1 x + b_1\\
h_1 &= \text{ReLU}(z_1)\\
z_2 &= W_2 h_1 + b_2 \\

\end{align}
$$
損失関数はCrossEntropyなので
$$
\hat y = \text{Softmax}(y_2)
$$
$$
L = \sum_i^C y_i\log \hat y_i
$$
これで計算する．

MLPクラスはnn.Moduleを継承している．継承することで
PyTorchがモデルの構造を管理できるようになる.
すなわちあとでパラメータ最適化を使うことができるのである．

## 正解ラベル，Loss，Optimizer，Accuracy

### 正解ラベル

Lossを計算するには，NNを通したあとの入力と正解ラベルが必要で，NNと入力は今実装したので，正解ラベルを仮に実装する．

```python
target = torch.randint(0,3,(32,))
```

これは上の入力と続いていて，0,1,2のどれかをランダムに32個生成している．すなわち32次元ベクトルを生成していると考えて良い．入力は10次元の特徴量を持ち，32個のデータがまとまっていると考えて良い．

これを我々はBatch学習と読んでいるのだった．

だから実際MLPの１層で計算しているのは
$$
Y = X W^T + b
$$
なのである．

### Loss 

Batchで出てくるのは$Z_2$,今回で言うと32×3の行列である．
これをそれぞれの列について，損失を取ると
$$
\mathbb L = [L_1,L_2 ,...,L_32]
$$
が出てきて，これをデフォルトでは平均して
$$
L = \frac{1}{32} \sum_{n =1}^{32} L_n
$$
をOptimizerに渡すのである．コードは
```python
criterion = nn.CrossEntropyLoss()
loss = criterion(logits, target)
```
である．

### Optimizer

あとは，Lossを用いて誤差逆伝播すればよい．

まずOptimizerを定義する必要がある．Optimizerは次のように実装される．今回はAdamを用いる．
```python
optimizer = optim.Adam(model.parameters(),lr = 1e-4)
```

これまでの流れは
$$
x \to Wx_1 +b_1 \to \text{ReLU} \to W_2h_1 + b_2 \to \text{Logits and Softmax} \to \text{CrossEntropy} \to L
$$
という流れだったわけだが，これは計算グラフで繋がっているのである．
なのでこれを逆向き，すなわちLossから誤差逆伝播すればよいのである．
なので実装は
```python
optimizer.zero_grad()
loss.backward()
optimizer.step()
```
となるのである．

optimizer.zero_grad()は勾配更新，
loss.bacward()は微分値の計算，
optimizer.step()は重み更新そのものである．

すなわち学習一回分のコードは以下のようになる．

```python
import torch
import torch.nn as nn
import torch.optim as optim


class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(10, 64)
        self.fc2 = nn.Linear(64, 3)

    def forward(self, x):
        x = self.fc1(x)
        x = torch.relu(x)
        x = self.fc2(x)
        return x


model = MLP()

x = torch.randn(32, 10)
target = torch.randint(0, 3, (32,))

criterion = nn.CrossEntropyLoss()

optimizer = optim.Adam(model.parameters(), lr=1e-4)

logits = model(x)

loss = criterion(logits, target)

optimizer.zero_grad()

loss.backward()

optimizer.step()

```

### Accuracy
あとは正答率を出してあげればどれだけ学習が成功しているか観察できる．

```python
with torch.no_grad():
    logits = model(x)

    pred = logits.argmax(dim=1)

    accuracy = (pred == target).float().mean()

    print("accuracy:", accuracy.item())
```

with torch.no_grad()は，勾配を計算しないということである．
logits.argmax(dim=1)は今回で言うと，列方向，での最大値のIndexを撮っているのである．例えば
```python
logits = torch.tensor([
    [0.2, 1.5, -0.3],
    [2.1, 0.4, 0.7],
    [0.1, 0.3, 1.2]
])
```
ではargmax(dim=1)を通すと
```python
tensor([1, 0, 2])
```
になることが分かる．
